
# Impact_of_Remote_Work_on_Mental_Health

# Phân tích Tác động của Hình thức Làm việc đến Sức khỏe Tinh thần

Dự án này là đồ án môn học "Trực quan hóa dữ liệu" tại Đại học Thủ Dầu Một, tập trung phân tích tác động của các hình thức làm việc (Remote, Hybrid, Onsite) đến sức khỏe tinh thần và sự hài lòng của nhân viên, đồng thời đề xuất giải pháp thông qua hai dashboard Power BI.

## Mục tiêu
- Dashboard 1: Trực quan hóa dữ liệu cơ bản về sức khỏe tinh thần và sự hài lòng.
- Dashboard 2: Phân tích tỷ lệ đề xuất chuyển đổi hình thức làm việc (RecommendationRate) và mức độ đề xuất (RecommendationLevel).

## Công cụ sử dụng
- **Python**: Xử lý và nhập dữ liệu từ CSV vào SQL Server.
- **SQL Server**: Lưu trữ và truy vấn dữ liệu.
- **Power BI**: Tạo dashboard tương tác với DAX measures.
- **Kaggle**: Nguồn dữ liệu (Impact_of_Remote_Work_on_Mental_Health.csv).

## Cấu trúc thư mục
- `data/`: Chứa tập dữ liệu (nếu được phép chia sẻ).
- `scripts/`: Script Python và SQL.
- `dashboards/`: Tệp Power BI.
- `docs/`: Báo cáo dự án (PDF).
- `images/`: Ảnh chụp dashboard.

## Hướng dẫn chạy dự án
1. Cài đặt SQL Server và Power BI Desktop.
2. Chạy các script SQL trong `scripts/` để tạo bảng và view.
3. Chạy `import_data.py` để nhập dữ liệu vào SQL Server.
4. Mở tệp `.pbix` trong Power BI và kết nối với SQL Server.

## Kết quả
- Dashboard cơ bản: Hiển thị các chỉ số như căng thẳng, cô lập xã hội, và sự hài lòng.
- Dashboard chuyên sâu: Đề xuất chuyển đổi hình thức làm việc dựa trên RecommendationRate.
